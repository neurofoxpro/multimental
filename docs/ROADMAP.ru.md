# Multimental — от идеи до Google Play

Источник: `.gameprod/workplan.json`. Обновлено: 2026-09-26.

**Исторически проверено не означает допуск текущего RC.** Невыполненный код не является ручной задачей.

## Работа одной командой

```text
npm run game -- next
npm run game -- task META-05
npm run game -- start META-05
npm run game -- check
npm run game -- ship META-05
npm run game -- resume-cycle
npm run game -- play-check
```

Dev APK продолжаются небольшими итерациями. Play не публикуется, пока инженерные, продуктовые и внешние gates не пройдены.

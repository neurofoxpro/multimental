## Что осталось проверить

Колоды этой серии те же семь специально выбранных архетипов. Поэтому превосходство стартовой/элитной колоды не следует автоматически переносить на отдельные карты: сначала нужны конкурентные смешанные составы и перекрёстные стратегии. Изменение выборочного процента между сериями не является изменением игры.

Лимиты и циклы по стратегиям: greedy: 0 / 0; positional: 0 / 0; random: 0 / 0. Все4704журнала новой серии воспроизведены. Число ходов и скорость компьютера не равны времени человека: цель10минут/предел15минут остаются отдельной проверкой. BALANCE-01 не закрыта.

Полная проверяемая квитанция: evidence/balance-heldout-20260928.json. Дизайн-лаборатория, принятие новых механик и чужая UI-ветка не изменялись.

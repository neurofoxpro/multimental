# Read-only диагностика второго USB-телефона

`npm run game -- fleet usb` сопоставляет число ADB USB-состояний с доступными Windows PnP-интерфейсами. Служебный PowerShell только читает Get-PnpDevice -PresentOnly и ContainerId. Серийные номера, PnP instance ID, GUID контейнеров и пользовательские имена не печатаются. Контейнеры заменены временными псевдонимами в пределах одного отчёта.

Два интерфейса ADB/MTP одного контейнера не считаются двумя телефонами. MTP/AndroidCandidate без ADB не доказывает авторизацию отладки. Ошибка USB может относиться к другому оборудованию. В отсутствие наблюдения нельзя утверждать, что проблема именно в драйвере, кабеле или разрешении.

Команда не перезапускает ADB, не ставит драйверы, не выдаёт разрешения, не меняет USB-режим, не выбирает новый телефон для установки. Ошибка чтения не подменяется пустым успешным списком. Развёртывание secondary и два физических матча остаются отдельной QA02.

Первоисточники: https://learn.microsoft.com/en-us/powershell/module/pnpdevice/get-pnpdevice ; https://learn.microsoft.com/en-us/windows-hardware/drivers/install/devpkey-device-containerid .

4. Не перезапускать готовую настройку Git/gh/ADB/эмуляторов и не удалять рабочие каталоги. Не изменять source при активном ops.lock; не удалять живые locks. На одном физическом телефоне не выполнять два тестовых цикла одновременно.
5. Продолжить первый непройденный gate нужного HEAD: audit → stage/candidate → qualify → merge только dev → CI/release → exact-commit delivery. После merge не создавать новый PR для повторения уже выполненных действий.

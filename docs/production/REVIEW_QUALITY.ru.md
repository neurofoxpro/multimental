# Ревью и рефакторинг серии 0.1.2

## Исправленные дефекты
1. Проверка относительных путей учитывает существующие родительские junction/symlink, даже когда создаваемого файла ещё нет. Windows absolute/UNC-пути отвергаются и при запуске теста на Linux.
2. Каталог с именем evidence внутри кода больше не исключается из fingerprint автоматически. Игнорируются только явно генерируемые пути/sidecar-файлы.
3. Квитанция не допускается, если команда меняла исходники или отсутствует хеш любого обязательного выходного файла.
4. Редактирование исходников вынесено в переиспользуемую функцию. При Windows EPERM существует журнал старого и нового текста; замена проверяется по хешу, параллельное изменение не затирается.
5. Русский changelog отделён от Git log. Схема, уникальные ID, русский текст, версии и актуальность сгенерированного файла проверяются. Повторная сборка не выдумывает новые возможности или факт установки.
6. Скрипты форматируются одним зафиксированным инструментом; контроль форматирования и статические ограничения CI входят в автоматическую проверку.

## Характер ревью
Это анализ кода и автоматические инвариантные проверки, а не выдуманный независимый человеческий review. Проверки включают отрицательные сценарии, затем headless-ядро/UI/протокол, два AVD и физические транспорты. Итоговые числа и ссылки на запуск берутся из фактического отчёта после цикла.

## Что остаётся отдельными задачами
Промышленная подпись, защищённое внешнее сетевое окружение, окончательный баланс, пользовательский PvP, экономика и production-аккаунты не объявляются готовыми на основании тестовой лаборатории. Права MAINTAIN не равны ADMIN. Тестовый сертификат не публикуется и не переносится в публичные assets.

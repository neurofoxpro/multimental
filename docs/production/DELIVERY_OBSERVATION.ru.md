# Фактическая доставка после исправления загрузчика

PR137 выпущен как0.13.1-alpha.242.1 и установлен на первом телефоне. Точная сводка: `docs/production/evidence/delivery-observed-20260926.json`. Обновлён существующий versioned-updater; Windows Task Scheduler показывает15-минутный предел и прежний ограниченный уровень исполнения.

Манифест и APK проверены по отдельным GitHub SHA-256; окончательная APK57 430 490байт скачана за один запрос. Продолжение после частичного ответа покрыто fault-тестами, но этот фактический перенос не объявляется продолжением старого потока. На установленной версии прошли inspector и smoke, с привязкой к хешу APK и сохранением постоянного сертификата.

На первой проверенной странице домашнего экрана значок игры не найден; это не вывод о всех страницах. На первом телефоне wireless debugging выключен, но сеть объявляет одну TLS-службу ADB. Пока не выполнена проверка её физической идентичности, она не считается вторым разрешённым телефоном.

AUTO-07 целиком остаётся открытой: завершена доставка и исходниковое продолжение прерванного UI, а восстановление каждой фазы sign/install и единый пакет следующему агенту требуют самостоятельной приёмки.

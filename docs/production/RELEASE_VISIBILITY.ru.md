# Доставка точно ожидаемого коммита

После PR10 Actions опубликовал alpha.48.1, но список релизов ещё возвращал alpha.34.1. Установщик правильно отказался понижать кандидат alpha.46.1; exit 0 не считался установкой новой версии. Возобновление установило alpha.48.1.

Теперь cycle и resume-cycle ждут точный merge commit с конечным таймаутом. Проверяются квитанция и реальный Android versionCode. Уже установленная ожидаемая версия — идемпотентный успех; устаревшая запись, другой коммит или нулевой код возврата без установки — не успех. Штатно отложенная доставка повторяется; ошибки целостности и подписи не скрываются. Пять регрессионных тестов покрывают эти случаи.

Игровые правила не меняются. Планировщик продолжает проверять dev prerelease раз в пять минут без удаления данных и без исполнения скачанных скриптов.

# Проверка редактора настоящими нажатиями Android

Команда: `npm run game -- device-suite --target phone --suite collection`. Перед ней нужны опубликованный APK с этим модулем и подтверждённая установка: `device-status`. Команда не собирает приложение и не считает старый smoke проверкой нового редактора.

На устройстве временно используется отдельный профиль в случайном каталоге, связанный с одноразовым nonce. Личный контроллер сохраняется и восстанавливается, а хеши личных поколений профиля и настройки проверяются до/после. Диагностический модуль доступен только в debug-сборке по одноразовому приватному запросу.

Реальные команды Android input tap проверяют восемь этапов: новая колода, добавление карты, удаление, повторное добавление, заполнение до 15, сохранение, выбор, запуск обычного матча. Тринадцать промежуточных карт добавляются API как подготовка фикстуры — это не выдаётся за тринадцать физических нажатий. Имя по умолчанию не проверяет ввод через клавиатуру.

Лаборатория также заново открывает диск и сверяет состав/выбор, затем сравнивает initial_decks реального запущенного матча с ожидаемым. Личный профиль не получает тестовые карты или статистику. Полная человеческая партия и субъективная удобность не выводятся из этого сценария.

Каждое нажатие связано с точными nonce, ожидаемым этапом и статусом running. Уже завершённый результат не разрешает новое нажатие по старым координатам. Снимки экрана имеют уникальный runId в имени и SHA-256 в отчёте. Запуск всей серии связывает фактически установленный APK и неизменные исходники инструментов.

После лаборатории приложение нужно закрыть/запустить обычным способом; диагностический процесс не является обычным пользовательским сеансом. Ошибка или таймаут сохраняются как ошибка, без автоматического удаления личных данных. Первый настоящий результат на Android записывается отдельно после выпуска; существование этой инструкции не доказывает его.

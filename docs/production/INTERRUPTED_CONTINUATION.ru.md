# Продолжение прерванного исходникового среза

Команда для прямого поручения владельца продолжить незавершённую разработку:

```text
scripts\chat.cmd collab continue-interrupted UX-07 NEW_UNIQUE_ALIAS
scripts\chat.cmd collab continue-interrupted UX-07 NEW_UNIQUE_ALIAS --apply
```

Первый вызов — только проверяемый план. Второй использует уже проверенную и влитую в dev реализацию. Он требует один неизменившийся открытый PR, чистое прежнее дерево, совпадающие local/remote HEAD, истёкший heartbeat, отсутствие активных CI и неизвестных/live locks, отсутствие changes requested и действующего guard прежнего дерева. Таймер сам ничего не захватывает.

Перед CAS наблюдение выполняется повторно под блокировками исходного и операторского дерева и интеграции dev. Один CAS отзывает предыдущий claim, освобождает операторскую задачу и создаёт новое владение теми же исходниковыми ресурсами. Старые token/fence больше не разрешают запись через прежний guard. Существующее дерево, branch, HEAD, незавершённый PR и все исходники остаются без изменений. Новый срез начинается от наблюдавшегося dev; незавершённые исправления переносятся адресно с provenance, а не force-push/rebase чужой ветки.

Текущий набор разрешает только source-only области UI/core/automation/economy/UX-research. Аппаратные ресурсы, устройства, подпись, активные исследования и незнакомые области не передаются этим маршрутом. Обнаруженный живой писатель/изменённое дерево/новый heartbeat/непроверенный оператор останавливает продолжение. Это кооперативные гарантии проверенных команд, не защита от администратора или чата, который намеренно обходит CLI.

Неполный или потерянный ответ CAS сначала проверяется по id операции в удалённом журнале. Повтор продолжает создание нового среза и запись комментария, а не меняет владение снова. Отсутствующая удалённая операция не выдаётся за успех. Операторская задача освобождается, но не принимается автоматически; AUTO-07 в целом ещё включает отдельные цепочки подписи/установки.

Основной результат — возможность вернуться к игровой разработке, сохранив недоделанный PR и запретив двум старым/новым писателям одновременно изменять один ресурс. Общая очередь work next по-прежнему никогда не отбирает просроченный claim.

## Wi-Fi

26.09.2026 владелец отдельно разрешил разработку и отладку по Wi-Fi. Используется штатный Android Wireless debugging и pairing; разрешение не подтверждает наблюдавшееся сопряжение. Нельзя автоматически подменять USB-физические устройства несколькими транспортами одного телефона или обходить запрещённый установщик беспроводным маршрутом. IP, pairing code и serial сохраняются только локально. Отдельные проверки — QA-02/QA-03 и реальная сеть, не этот source-only адаптер.

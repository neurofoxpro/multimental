# Коллекция и пользовательские колоды: проверяемое ядро

Этот инкремент реализует данные и API, не экран редактора. Пользовательское меню по-прежнему запускает прежнюю стартовую колоду. Issue31 остаётся открытой до интерфейса, выбора перед боем и согласования колод в LAN/Bluetooth.

## Политика тестовой коллекции

`deck_rules.gd`: 15 карт, не более двух одинаковых, свободное смешивание всех десяти стихий. Стабильные коды c000–c029 не зависят от языка. Это рекомендованная alpha-политика `alpha-15-two-copies-v1`, не окончательный баланс и не новый круг контрстихий.

`collection_init` однократно выдаёт по две копии 30 текущих карт и создаёт starter. Команда пока используется лабораторией и программным API; личный профиль автоматически не пополняется. Повтор не увеличивает количество копий. Неизвестная непустая старая коллекция не заменяется стартовой.

`deck_save` сохраняет именованную колоду или неполный черновик; максимум 12 колод. `deck_select` допускает только полную законную колоду. Редактирование выбранной колоды до неполной снимает выбор. `deck_delete` удаляет запись колоды, но не карты. Все команды проходят существующий журнал профиля и двухпоколенное сохранение. Колоды не резервируют копии друг у друга: одновременно играется одна.

## Матч и повтор

`MatchCore.start_with_decks(seed, [left, right])` валидирует оба состава до изменения состояния. Входные массивы копируются, изменение исходного списка не меняет начатую партию. Старый start(seed) сохраняет прежний seeded baseline.

Повтор принимает опциональный исходный набор колод третьим аргументом. Локальный AI replay теперь содержит initial_decks; публичная сетевая проекция их не получает. Нельзя выдавать ядро этого API за завершённое согласование сетевых колод: транспорт пока не изменён.

`catalog_view.gd` формирует данные каталога, поиск по RU/EN и фильтр стихии; не создаёт экран и не меняет профиль. Имена/описания остаются данными, не командами.

## Проверки и ограничения

`npm run game -- profile-test collection` проверяет данные, повторы, лимиты, диск и 40 seeded матчей с разными колодами. Набор встроен в общий verify. Android profile-suite дополнен реальными записями коллекции/выбора только в случайном тестовом каталоге; личные a/b-файлы сравниваются до/после.

Новый формат коллекции в сохранении приводит к отказу unsupported, не к молчаливому восстановлению старой копии поверх будущих данных. Локальная коллекция не является доверенной серверной экономикой. Магазин, паки, крафт, аккаунт и рейтинг не реализованы этим инкрементом.

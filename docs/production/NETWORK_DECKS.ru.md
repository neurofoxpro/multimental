# Собственные колоды в LAN и Bluetooth

В обычном сетевом меню показывается выбранная колода и доступен переход к редактору. Перед созданием или входом берётся проверенный снимок выбранного состава. Неполная/невыбранная колода не заменяется молча на стартовую. Диагностический режим с отключённым личным профилем отдельно использует тестовый STARTER.

Протокол комнат теперь v3. Hello содержит версию, ID правил, capability комнаты, identity участника, deck_policy и 15 ID карт. Старый v2, отсутствующий/неверный состав, неизвестная политика и дополнительные поля отвергаются. Обновиться должны обе стороны. Формат сохранений профиля и принятые боевые правила не меняются.

Хост валидирует оба состава до первого хода, копирует их и запускает то же детерминированное ядро. Повторное подключение допускает прежнюю identity только с тем же упорядоченным составом. Даже перестановка карт при reconnect не меняет начальное распределение. Повтор не перезапускает игру и не переигрывает сделанные ходы.

В LAN гостевой состав отправляется только хосту внутри соединения TLS с проверенным сертификатом; Bluetooth использует прежний защищённый RFCOMM. Полные составы, seed и скрытая рука не появляются в публичных проекциях. Хост в локальном режиме доверенный: его владелец технически может изучить авторитетное состояние. Это не античит внешнего сервера и не проверка серверного владения коллекцией.

Локальный UI берёт карты из сохранённой коллекции, чистая сетевая проверка гарантирует длину, известные ID и лимиты копий. Отсутствие платной экономики в alpha не превращает клиентскую коллекцию в доверенную онлайн-экономику.

Проверки: `profile-test network` (авторитет, hello, неизменность, приватная проекция), `profile-test editor` (выбор и запрет fallback), полный `check` (настоящий TLS loopback и модель Bluetooth с разными составами). Аппаратная команда `bluetooth-room` использует Windows-гостя с отличным от Android-host STARTER составом; положительный физический результат записывается отдельно на точной версии APK.

Не выдавать loopback за Wi-Fi, fake radio за Bluetooth и Windows ↔ Android за два физических Android. Результаты реального устройства, переподключения и установки остаются отдельными квитанциями.

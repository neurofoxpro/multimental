# Проверяемая очистка рабочих веток

Команды: `npm run game -- branches plan` и `npm run game -- branches apply`. На станции эквивалентен `scripts/chat.cmd branches ...`. Разрешён только neurofoxpro/multimental; контекст и fetch/push origin проверяются. Рабочие деревья и сами исходники не удаляются.

## Отбор

Удаляются только refs/heads с префиксом feature/fix/docs/test, у которых точный текущий SHA совпадает с head уже объединённого PR в dev. Commit должен быть предком конкретного наблюдаемого dev. Отдельно исключаются открытые PR, ветки незавершённых Actions и ветки любого зарегистрированного локального worktree.

main/dev, теги, неподтверждённые и изменившиеся ветки не являются кандидатами. Если локальной истории недостаточно для доказательства родословной, ветка остаётся в unproven, а не удаляется по догадке. Другие доказанные кандидаты можно обработать независимо.

## Атомарная операция

Используется GraphQL updateRefs: beforeOid равен проверенному SHA, afterOid — нулевой OID, force=false. В ту же атомарную операцию включён guard dev: beforeOid и afterOid совпадают. Если один ref или dev изменился, пакет отклоняется целиком. Никакого force-push или переписывания истории.

Первичный источник API: https://docs.github.com/en/graphql/reference/git#updaterefs

Пакет ограничен 50 ветками. До mutation сохраняется план, после — повторно читаются refs. Потерянный ответ не вызывает слепого повторного удаления. Незавершённая запись остаётся незавершённой; успешный exit не выводится из отсутствия исключения.

Операция не делает распределённую блокировку чужих интерфейсов GitHub: наличие открытых PR/Actions проверяется снимком, а точные refs защищены серверным compare-and-swap. Коммиты остаются достижимыми из dev. Не обещать удалить ветки, если readback не подтверждён.

## Производственный порядок

Сначала тесты и `branches plan`, затем просмотр ограниченного плана и `branches apply` в рамках уже данного владельцем разрешения на очистку влитых веток. Результат и сохранённые исключения записываются в Issue #29. Очистка не должна блокировать выпуск из-за одной неподтверждённой старой ветки.

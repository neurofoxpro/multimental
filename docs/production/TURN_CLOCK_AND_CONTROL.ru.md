# TURN-01 — тестовое время хода

На первый **личный** ход каждого игрока отводится 90 секунд. Второй ход того же игрока — 95 секунд, третий — 100, далее +5 секунд на каждый следующий личный ход. Это не накопление остатка от предыдущего хода: после завершения хода остаток не переносится. Прибавка временная и меняется отдельно одним параметром `TEST_BONUS_MS`.

Порядок ходов в `MatchCore` чередуется. `turn_clock.gd` вычисляет бюджет из общего номера хода: 1/2 = 90 сек; 3/4 = 95; 5/6 = 100. Одна и та же функция используется локальной дуэлью и авторитетной LAN-комнатой. Сервер остаётся источником времени; подключённый клиент только отображает оставшиеся миллисекунды. После подтверждённого завершения хода счётчик стартует заново; при просроченном таймере после сворачивания ход учитывается относительно исходного дедлайна, а не нынешнего момента.

Существующий общий предел партии 15 минут оставлен без изменений: это отдельное правило, изменение которого пользователь пока не запрашивал. Подпись, каталог карт, очки, урон, стоимость, экономика, seed/replay не меняются.

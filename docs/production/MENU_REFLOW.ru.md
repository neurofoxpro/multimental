# Первый инкремент UX-07: доступное главное меню

Исследование UX06 обнаружило частично обрезанные кнопки при настоящем1280×720 viewport. Меню теперь использует общий ScrollablePage: оно остаётся внутри отведённой области, а содержимое прокручивается без уменьшения текста или hit-targets. Горизонтальная прокрутка выключена.

Начальный focus назначается кнопке AI, Tab идёт по обычному дереву, прокрутка следует за focus. Общая фабрика кнопок рисует явную рамку. Это не обещание полноценного screen-reader support. Safe-area обработка нестандартных вырезов, физические dp, подробная карта-инспектор и художественная полировка остаются следующими частями UX07.

`profile-test menu` проверяет233 условий для двух языков и720×1280,720×1440,1280×720,640×480: реальный viewport, досягаемость каждой кнопки прокруткой, начальный focus, настоящее событиеTab и отсутствие скрытой выдачи коллекции. `ux-audit` повторяет24 измерения: непрокручиваемого обрезания меню больше нет.

При проверке найден и исправлен deferred-focus на уже удалённый экран: используется WeakRef и проверка нахождения Control в дереве. Локальный profile-test теперь отвергает ERROR даже после PASS-маркера;13 Node-регрессий проверяют этот контракт. Первый пробный запуск с таким ERROR не считается пройденным итоговым тестом.

Следующий инкремент интерфейса должен переиспользовать wrapper и focus-contract, а не повторять размеры/поведение в каждой сцене. Экономический срез развивается отдельно; после merge его refresh обязан сохранить локальный draft или остановиться при пересечении путей.

# Производственный цикл v2

## Единая команда чата
В каталоге repo запускается powershell -File scripts/chat.ps1 КОМАНДА. Скрипт сам находит локальный MinGit и Godot, проверяет компьютер, origin и профиль. Git и gh не требуют передачи токена в чат.

Команды: resume; begin feature/имя; apply пакет.json; verify; publish; wait номерPR; integrate номерPR; wait-dev SHA; cycle; logs RUN_ID; device-status; delivery; device-test; network; emulator start A; emulator stop A; roadmap.

cycle повторяет проверку, коммитит и публикует ветку, открывает PR, дожидается конкретного HEAD и успешных проверок, объединяет только в dev и дожидается dev CI. Ожидание ограничено таймаутом и возобновляется командой wait. main/stable не являются командами ops.

Обычная работа использует Git working tree вместо нового ZIP на каждый коммит. Публикация — от venelsendrik с правами MAINTAIN. Браузер и новый токен не нужны. MAINTAIN не является ADMIN; branch protections и секреты при необходимости требуют отдельного полномочия.

## Ускорение
PR запускает один CI вместо дублирования каждого push feature-ветки. Документация/roadmap проходят metadata/security-проверки без нового APK. Код проходит полные тесты и универсальный arm64/x86_64 экспорт. Инструменты фиксированы хешами; шаблоны кэшируются, извлекаются только Android/Web. Actions зафиксированы SHA. Версия выводится из package.json и монотонного номера workflow.

## Испытания
Правила и контракты — headless/unit. Интерфейс, сохранения, перезапуск и чистая установка — выделенные Android AVD A/B. Реальные Wi-Fi/Bluetooth, USB и производительность — явно разрешённый телефон и адаптер станции. Виртуальные радио netsim не доказывают реальное радиосоединение.

Debug-лаборатория вызывается одноразовым private automation-request.json, ограничена временем и случайным nonce. Она не выполняет произвольный код, не включается в обычной игре. Полное PvP-лобби — отдельный этап roadmap.

## Закрытие и переустановка
Последним поручением разрешено закрывать тестовую игру перед новой установкой. На телефоне — force-stop только pro.neurofox.multimental.dev, install -r, проверка готовности. Данные и постоянная подпись сохраняются. clean-install отвергает телефон и проверяет имя выделенного AVD. Тестовый lock блокирует параллельный обновлятор.

## Доказательства
Квитанции содержат хеши, команды, время и фактический результат; изменение исходников внутри проверки немедленно означает FAIL. Отчёт сохраняется при ошибке. USB-туннель не выдаётся за Wi-Fi. Полная ручная приёмка игры не заменяется лабораторным тестом протокола.

Обновлятор использует отдельно развёрнутую проверенную копию скриптов, а не запускает новые файлы из GitHub автоматически. Обновление самой копии — отдельная проверяемая операция.

## Полный цикл и восстановление

Команда cycle теперь включает подготовку кандидата, две AVD, JNI/UI/переустановку/межклиентский обмен, допуск dev, публикацию, развёртывание проверенного установщика, доставку на телефон и локальную сводку. Опция --physical дополнительно требует настоящие LAN и Bluetooth. Для прицельной диагностики — prepare и probe-bluetooth. После прерывания уже объединённого изменения — resume-cycle с проверкой совпадения HEAD. report --write формирует безопасные файлы состояния для отдельного docs-only PR без лишнего APK.

Один изменяющий ops-процесс одновременно. Ошибки неправильного репозитория, имени AVD, подписи, устаревших квитанций и параллельного владельца устройства блокируют работу. Предупреждение Android о полноэкранном режиме не считается ошибкой игровой логики: оно обрабатывается только в выделенном эмуляторе и только по точному системному ресурсу.

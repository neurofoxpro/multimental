# Multimental — профиль и продолжение

Основная память: GitHub Issue #29, задача META-05 #30. Сначала live Issues и skill; этот файл — снимок текущей разработки, не квитанция релиза.

Ветка feature/profile-store-20260926 от acd572a2c47f5102e130db7f97929fce7d027920. В этой ветке добавлены дисковый профиль с двумя поколениями, компактный упорядоченный журнал, перенос языка, сохранение результатов AI/LAN/Bluetooth и отдельный Android-тест в изолированном каталоге. Последний AI replay сохраняется вместе со статистикой; сетевой итог не содержит скрытых данных.

Локально проверены 406 storage-проверок и 20 UI-проверок, включая настоящий seeded матч и восстановление точного состояния из сохранённого replay. Для окончательного допуска перечитать текущий CI и исходники: после изменения старые тесты не переносятся автоматически. Версия исходников 0.6.0-alpha.1; фактический номер APK определяет CI.

Команды: profile-test model|storage|ui, check, publish, wait-dev SHA, delivery, device-suite --target phone --suite profile. Всегда через npm run game -- или scripts/chat.cmd. Проверять реальный installed APK до/после. Переустановка той же версии должна сохранить профильные файлы и прежнюю подпись.

На старте этой итерации телефон действительно работал на .131.1; установка нового профиля ещё требует отдельного live readback. Новая коллекция/магазин/крафт не реализованы этим хранилищем. После завершения #30 — #31. Cloud-sync, полноценный автономный merge-flow и Play остаются отдельными задачами. Main/stable/Play не менять без согласия, телефон не очищать.

# История изменений Multimental

Этот файл генерируется из changes/fragments. Записи описывают изменения для человека, а не сырой Git log.
Базовые версии обозначают серии разработки, не факт выпуска stable. Точный номер alpha, commit и проверки опубликованы в GitHub Release.

Порядок разделов основан на Keep a Changelog; совместимость — по согласованному SemVer.

## 0.2.0 — текущая серия разработки

### Добавлено

- Все требования чата сведены в машиночитаемый реестр; gate готовности к бете отличает невыполненную реализацию от действительно ручной оценки и запрещает выдавать одно за другое.
- Добавлены создание LAN-комнаты и подключение второго игрока по приватному приглашению, авторитетные ходы двух игроков, защищённый TLS-канал и автоматическое переподключение.
- Добавлен проверяемый реестр исследований: вопрос, рекомендация, первоисточник, связанные тесты и ограничения. Рабочий инструмент проверяет реестр и сохраняет хеши исследованных источников.

### Исправлено

- Для временного fetch failed и HTTP 502/503/504 при чтении метаданных добавлен ограниченный повтор. Ошибки доступа, rate limit, неверный JSON и превышение размера не обходятся.
- При создании комнаты Wi-Fi и проводная локальная сеть предпочитаются VPN и мобильному интерфейсу; подходящий адрес можно явно выбрать в лобби.
- Сериализация сертификата комнаты изолирована от ошибки NUL в Godot; проверка сертификата и имени узла остаётся включённой, приватный ключ не записывается на диск.
- Офлайн- и сетевой интерфейсы используют одну проекцию состояния без чужой руки; причины завершения переведены на русский и английский, а завершение по таймеру сохраняется.
- Чтение GitHub повторяется только при временных сетевых сбоях; результат неоднозначного merge проверяется без повторной записи. Параллельная установка корректно откладывается, не удаляя живой lock.

## 0.1.2 — предыдущая серия alpha

### Добавлено

- Русская история изменений генерируется из проверяемых записей; CI проверяет актуальность, а GitHub Release получает русские заметки без ручной копипасты.

### Безопасность

- Усилены проверки путей, исходников, артефактов и допуска релиза; отрицательные сценарии и изменения квитанций покрыты регрессионными тестами.

## 0.1.1 — предыдущая серия alpha

### Добавлено

- Рабочий цикл git/gh, проверяемые квитанции, два Android-эмулятора, установка на телефон и последующие обновления.
- Лабораторная сессия проверена через реальный LAN и RFCOMM Bluetooth при выключенном Wi-Fi; пользовательское PvP-лобби в эту версию не входит.

### Исправлено

- Устранены изменение исходников при тесте, случайная UI-фикстура, конфликт установщика с испытаниями и преждевременное принятие доставки.

## 0.1.0 — предыдущая серия alpha

### Добавлено

- Первая офлайн-альфа: поле 3×3, пять стихий, случайная рука, соседние атаки, ИИ и интерфейс RU/EN.

## Проверки и ограничения

Автоматические проверки и установка привязаны к конкретному APK; их результаты не выводятся из списка изменений.
Ручная приёмка: docs/MANUAL_TESTS.ru.md. Полный план: docs/ROADMAP.ru.md.

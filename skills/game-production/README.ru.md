# Скилл производства игр

Вход: [SKILL.md](SKILL.md). Рабочий профиль Multimental: [../../.gameprod](../../.gameprod).

```
npm run production -- status
npm run production -- next
npm run verify
npm run production -- gate verified
npm run build:android
npm run production -- gate android-built
```

Нужно работать из проверенного checkout или снимка, на явно разрешённом компьютере. Переменная GODOT_BIN указывает на зафиксированный Godot. В CI пути и stamp версии задаёт workflow.

Для нового проекта скопировать каталог skill в существующий Git-репозиторий и вызвать `node skills/game-production/scripts/init.mjs --root ПУТЬ --repository OWNER/REPO --host ИМЯ_КОМПЬЮТЕРА --name ИМЯ_ИГРЫ`. Репозиторий удалённо не создаётся, старый профиль не заменяется. В новом профиле нужно явно задать тестовые/сборочные команды движка: пустые gates не считаются выполненными.

Все 25 этапов представлены в lifecycle. Не каждому этапу соответствует автоматическая программа: концепция, лицензия, продуктовые решения и ручная приёмка — отдельные gates. Сейчас программно реализованы проверки контекста, metadata, тесты/сборка/квитанции, публикация dev через Actions и безопасная установка/обновление Android. Генераторы контента и новые игровые системы добавляются как отдельные проверяемые инкременты.

После потери контекста сначала status + внешний Git/CI/реальный device receipt. Не выдумывать факт установки, не выводить его из старого сообщения чата и не повторять настроенный конвейер с нуля.
